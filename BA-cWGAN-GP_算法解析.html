▼
1 Phase 1：违约倾向得分提取 — 从右删失样本中"榨取"信息

📋 操作流程

  1. 从月度 Performance 数据中回溯每笔违约贷款的首次违约月份
  2. 贴标签：first_default_month ≤ 12 → Early Default；>12 → Late Default
  3. 训练 speed_clf（XGBoost 二分类器）学习"特征 → 违约速度"映射
  4. 对全部违约样本（含右删失 8,150 笔）预测 r = P(Early Default)

📊 输出

违约倾向得分 r ∈ [0, 1]

  • r 越大 = 越倾向快速违约（高风险模式）
  • r 越小 = 越倾向缓慢违约（低风险模式）

预实验中 speed_clf 在 27,261 条标注样本上训练，r 分布：mean=0.406, std=0.074

💡 本质：右删失样本"我知道它是违约，但不知道第几个月违约" → speed_clf 推断 "这笔有 87% 概率属于快速违约型" → r = 0.87 作为 Phase 3 的条件引导信号
▼
2 Phase 2：决策边界识别 — 找到最有价值的违约样本

📋 操作流程

  1. 在完整 GAN 训练集上训练 base_clf（XGBoost）
  2. 对每个违约样本预测违约概率 p
  3. 计算边界距离 d = |p − 0.5|
  4. 计算采样权重 w = 1 / (d + 0.01)
  5. 训练 NN 代理模型实现知识蒸馏（用于 Phase 3 可微分边界损失）

📊 边界距离含义

p 值d 值含义生成优先级
0.920.42分类器很确定是违约低 w=2.4
0.550.05分类器很犹豫高 w=16.7
0.480.02分类器差点判为正常最高 w=33.3

预实验：NN 代理 r=0.983，边界一致性 94.2%，知识蒸馏成功

判别器损失（与 WGAN-GP 一致）： LD = D(x_fake) − D(x_real) + 10.0 · GP ， 其中 GP = 𝔼[(∥∇x̂D(x̂)∥₂ − 1)²]（梯度惩罚，保证训练稳定）

🎯 边界损失的直观含义

base_clf 对 x_fake 的预测distance = |p − 0.5|边界损失值效果
p = 0.95（"这肯定是违约"）0.45-0.45被惩罚！
p = 0.55（"可能是违约吧"）0.05-0.05几乎不惩罚
p = 0.50（"完全拿不准"）0.00 0.00理想状态！

→ 生成器被逼着往分类器最不确定的区域生成样本，这些样本对下游模型训练价值最大

出 输出：高质量合成违约样本

🎯 边界富集

生成样本集中在决策边界附近（预实验：59.2% vs WGAN-GP 33.2%），对下游分类器训练价值最大

📐 条件可控

通过调节 r 值可以定向生成"快速违约型"或"缓慢违约型"样本，满足不同应用场景需求

🔍 后筛选

用 base_clf 检查生成质量：保留 p ∈ [0.3, 0.7] 的样本，丢弃远离边界的低质量生成

最终产出：合成违约样本 + GAN 训练集真实样本 → 均衡训练集 → 交给下游 Stacking 集成模型（第二章）做最终预测

# ===== Phase 1: 违约倾向得分 ===== for loan_id in default_loans: # 从月度 Performance 数据中回溯首次违约月份 first_default_month = find_first_dlq3_or_zbc_event(loan_id) # 贴标签：≤12月→Early, >12月→Late y_speed = [1 if m <= 12 else 0 for m in first_default_months] # 训练二分类器区分 Early vs Late speed_clf = XGBoostClassifier() speed_clf.fit(X[default_loans], y_speed) # 对全部违约样本（含右删失）预测 r r_train = speed_clf.predict_proba(X[default_loans])[:, 1] r_censored = speed_clf.predict_proba(X[censored_loans])[:, 1] # ===== Phase 2: 决策边界识别 ===== base_clf = XGBoostClassifier() base_clf.fit(X_train, y_train) # 完整训练集 p = base_clf.predict_proba(X_minority)[:, 1] d = |p - 0.5| # 边界距离 w = 1 / (d + 0.01) # 加权采样权重 # 训练 NN 代理模型（知识蒸馏，用于 Phase 3 可微分边界损失） surrogate_base = NN(); surrogate_base.fit(X_minority, p) surrogate_speed = NN(); surrogate_speed.fit(X_minority, r) # ===== Phase 3: BA-cWGAN-GP 训练 ===== G = Generator(input_dim=101) # 100(z) + 1(r) D = Discriminator(input_dim=13) for epoch in range(n_epochs): for (x_real, r_batch) in WeightedSampler(X_minority, r_train, w): # --- 训练判别器 --- z = randn(batch, 100); zc = [z, r_batch] x_fake = G(zc).detach() L_D = D(x_fake).mean() - D(x_real).mean() + 10.0 * GP D_optimizer.step(L_D) # --- 每 5 步训练一次生成器 --- if step % 5 == 0: x_fake = G([randn(batch,100), r_batch]) L_adv = -D(x_fake).mean() L_boundary = -|surrogate_base(x_fake) - 0.5|.mean() L_r = |surrogate_speed(x_fake) - r_batch|.mean() L_G = L_adv + 0.1 * L_boundary + 0.05 * L_r G_optimizer.step(L_G) # ===== 生成 + 筛选 ===== synthetic = [] while len(synthetic) < target: r_sample = sample_from_empirical_r_distribution(batch) x_fake = G([randn(batch,100), r_sample]) prob = base_clf.predict_proba(x_fake)[:, 1] synthetic.extend(x_fake[(prob >= 0.3) & (prob <= 0.7)])
